The audit's original BT.1886/Rec.709/checksum/geometry/budget calculations stand. Independent Decimal/Fraction recomputation checked the review additions without importing colour software or operating equipment. All luminances below are **hypothetical**, not readings. Using BT.1886 gamma 2.4:

- For the hypothetical rounded mapping `floor(16+219*k/255+.5)`, k=0…255, there are 220 distinct results and 36 colliding adjacent pairs; planned T-005 optical codes remain distinct. This supports Claude's arithmetic, not a measured pipeline.
- With independent normal samples, equal variances and n=3 in each T-005 group, Student t has 4 degrees of freedom and t=3 gives two-sided **p=.0399419681**, not the normal 3-sigma p=.0026997961. Unequal variances change Welch degrees of freedom (toward 2 here); drift/correlation can invalidate that model. The active max-with-2q rule is a heuristic with a quantisation floor, not this p-value as an automatic guarantee. T-003's n=5 individual-spread threshold corresponds to 3√5≈6.708 mean-standard-errors under the same simplified assumptions.

Reproduce the core numeric correction with an ordinary Python interpreter; this uses only the standard library:

```python
from math import floor, log2, sqrt
g = 2.4
def parameters(w, b):
    d = w**(1/g) - b**(1/g)
    return d**g, b**(1/g)/d
def luminance(v, w, b):
    a, lift = parameters(w, b)
    return a * max(v + lift, 0)**g
print(parameters(100, .04))
print([luminance(k/255, 150, .05) for k in (51, 26, 13, 5, 0)])
codes = [floor(16 + 219*k/255 + .5) for k in range(256)]
print(len(set(codes)), sum(a == b for a, b in zip(codes, codes[1:])))
z = 3/sqrt(13)
print(log2(220), 1 - 1.5*z + .5*z**3)  # t(4) two-sided tail at 3
```
