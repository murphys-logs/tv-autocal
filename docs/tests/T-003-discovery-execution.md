```text
$t003Exit = 'UNRECORDED'; $t003Start = Get-Date; try { & '<SELECTED-ABSOLUTE-SPOTREAD-PATH>' '-?' 1> '<FRESH-PRIVATE-STDOUT-PATH>' 2> '<FRESH-PRIVATE-STDERR-PATH>'; $t003Exit = $LASTEXITCODE } finally { $t003End = Get-Date; "EXIT=$t003Exit START=$($t003Start.ToString('o')) END=$($t003End.ToString('o'))" }
```

Prepare the **whole line before pressing Enter**, including the automatic recording after the invocation. The `try`/`finally` statements are shell bookkeeping around that one direct invocation, not process supervision or a retry.
